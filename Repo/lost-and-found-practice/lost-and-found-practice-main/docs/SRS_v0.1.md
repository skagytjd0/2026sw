# 교내 분실물 관리 서비스 SRS v0.1

## 1. 목적 및 범위

이 문서는 교내 분실물 관리 서비스의 기능 요구사항, 비기능 요구사항 및 정책을 정의한다. 서비스 이용자는 방문 전에 분실물의 보관 여부와 위치를 확인한다. 습득 학생은 습득한 물품을 앱으로 바로 등록하고, 행정 담당자는 분실물 센터로 접수된 습득 물품을 등록·관리하며 보관·인도 상태를 관리한다.

현재 범위는 텍스트 및 기본 조건을 이용한 분실물 조회, 분실물 정보 등록·관리, 담당 부서 문의 방법 안내이다. 사진 자동 매칭, 자동 알림, 개인 휴대전화 번호 공개 및 학교 인증 연동은 현재 개발 범위에서 제외한다.

## 2. 기능 요구사항

| ID | 요구사항 | 우선순위/비고 |
|---|---|---|
| FR_00 | 이용자는 분실물 목록을 조회할 수 있어야 한다. | 검색 조건 및 공개 항목은 확정 필요 |
| FR_01 | 이용자는 분실물의 보관 여부와 보관 위치를 확인할 수 있어야 한다. | 방문 전 확인 목적 |
| FR_02 | 이용자는 담당 부서에 분실물 관련 문의를 할 수 있도록 문의 방법을 확인할 수 있어야 한다. | 구체적인 안내 문구·연락 경로는 확정 필요 |
| FR_03 | 습득 학생은 습득한 물품을 앱으로 바로 등록할 수 있어야 한다. | 확정된 등록 경로. 등록 항목·인증·승인 여부 미정 |
| FR_04 | 행정 담당자는 등록된 분실물 정보를 조회하고 관리할 수 있어야 한다. | 관리 범위와 권한은 확정 필요 |
| FR_05 | 행정 담당자는 물품 상태를 보관 중 또는 인도 완료로 구분하여 기록할 수 있어야 한다. | 상태 변경 조건·확정 절차는 확정 필요 |
| FR_06 | 행정 담당자는 분실물 센터로 접수된 습득 물품을 관리하기 위해 물품 정보를 등록할 수 있어야 한다. | 확정된 등록 경로. 필수 항목과 등록 권한은 확정 필요 |

## 3. 비기능 요구사항

원문에 정량 목표가 없으므로 아래 수치는 초기 제안값이다. 운영 환경과 예상 사용량을 확인한 뒤 검증 환경 및 목표를 조정한다.

| ID | 품질 특성 | 요구사항 | 측정 기준 |
|---|---|---|---|
| NFR_00 | 성능 | 분실물 조회 요청은 정상 처리 기준으로 2초 이내에 응답해야 한다. | 등록 데이터 10,000건, 동시 사용자 100명 조건에서 응답시간 95백분위수 ≤ 2초 |
| NFR_01 | 성능 | 물품 등록 및 상태 변경 요청은 정상 처리 기준으로 2초 이내에 완료되어야 한다. | 동시 사용자 100명 조건에서 처리시간 95백분위수 ≤ 2초 |
| NFR_02 | 가용성 | 서비스 월간 가용률은 99.5% 이상이어야 한다. | 예정된 정기 점검 시간을 제외하고 월 단위 측정 |
| NFR_03 | 사용성 | 행정 담당자는 필수 정보를 입력해 물품 1건을 등록하는 데 2분 이내가 걸려야 한다. | 사전 교육을 받은 담당자 5명 이상이 각 5건 등록한 시간의 중앙값 ≤ 2분/건 |
| NFR_04 | 데이터 반영 시간 | 물품 상태 변경 결과는 조회 화면에 5초 이내 반영되어야 한다. | 상태 저장 완료 시점부터 조회 결과 반영까지 ≤ 5초 |

## 4. 정책

| ID | 정책 | 근거/비고 |
|---|---|---|
| Pol_00 | 데이터는 가상 데이터를 사용한다. | 공통 제약 C_1 |
| Pol_01 | 실제 개인정보는 수집하거나 사용하지 않는다. | 공통 제약 C_1 |
| Pol_02 | 학교 인증 시스템과 연동하지 않는다. | 공통 제약 C_1 |
| Pol_03 | 개인 휴대전화 번호를 공개하지 않는다. | NEEDS_6, 범위 SC8 제외 |
| Pol_04 | 물품 정보는 보관 중인 물품과 인도 완료 물품을 구분해 관리한다. | SC3 |
| Pol_05 | 사진 등록 및 사진 기반 유사 물품 매칭은 현재 개발 범위에서 제외한다. | SC5 제외 |
| Pol_06 | 사진 매칭 결과 자동 알림은 현재 개발 범위에서 제외한다. | SC7 제외. 수신 정보 등록·발송 기능도 범위 밖 |
| Pol_07 | 담당 부서 문의 방법 안내는 제공하되, 개인 연락처 공개와 구분한다. | SC6 포함, SC8 제외 |
